# BotPag - Formatador de Planilhas`n`nFerramenta complementar para preparar planilhas de referencia usadas pelos robos de pagamentos.`n`n## Funcionalidades`n- Padroniza CPF, valor, banco, agencia, conta e datas.`n- Preenche campos repetidos em blocos na aba Entrada.`n- Mantem determinadas abas somente com cabecalhos.`n- Gera Pagamentos_Tratado.xlsx sem sobrescrever Pagamentos.xlsx.`n`n## Uso`n1. Mantenha Pagamentos.xlsx na mesma pasta.`n2. Feche Pagamentos_Tratado.xlsx se estiver aberto.`n3. Execute Iniciar_BotPag_Formatador.bat.`n4. Revise o resultado antes de usar nos demais robos.`n`n## Arquivos`n- Formatar_planilha.py: codigo-fonte.`n- BotPag-Formatador.exe: executavel Windows.`n- Iniciar_BotPag_Formatador.bat: inicializador.`n- Instalar_Dependencias.bat: dependencias para desenvolvimento.`n- Pagamentos.xlsx: modelo de referencia sem registros de pagamento.`n`n## Seguranca`nA planilha foi preparada sem registros de pagamento. Nunca publique planilhas operacionais com dados pessoais ou bancarios reais em repositorios publicos.
